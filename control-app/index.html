Full Connection Path

The complete system should turn every input into a governed event, route it through context and policy, then only act after verification.

1
Inputs
Website form, owner chat, future voice, email, SMS, files, browser actions, and Shopify events all become one standard event envelope.
2
Identity And Context
Resolve who the request is from, what project it belongs to, which permissions apply, and what prior memory is allowed.
3
Planning And Agent Routing
Planner creates tasks. Router chooses OpenAI, Claude, or a specialist. Supervisor checks evidence, gaps, risk, and owner rules.
4
Policy Gate
Anything involving money, customers, credentials, permissions, production, deletion, or external sending is blocked or approval-gated.
5
Execute And Verify
Approved actions run through n8n or backend tools. The result must return proof: message ID, row ID, file ID, commit SHA, or deployment ID.
6
Memory Write
Only verified, non-secret, correctly scoped facts become long-term memory in Postgres. Ambiguous or risky facts stay pending.

Security Gates

The system should fail closed. If safety, authority, scope, destination, or verification is missing, the action stops.

GateRequired CheckFailure Behavior
Root authorityDominique Reed is final authority for restricted actions.Stop and request owner approval.
Credential scopeNo secret values in browser, emails, Sheets, Drive docs, prompts, or customer replies.Deny and log as credential exposure risk.
Destination allowlistEmail addresses, Sheet IDs, Drive folder IDs, APIs, and domains must be explicitly approved.Block until allowlist entry exists.
Policy classCustomer reply, quote, payment, production deploy, access sharing, deletion, and credential changes need approval.Create approval request, do not execute.
RollbackDestructive or production actions need rollback and verification methods.Deny if rollback is missing.
VerificationExecuted action must return proof such as message ID, row range, file ID, or deployment ID.Do not write success memory.
Memory writeOnly verified, scoped, non-secret information can become memory.Store as candidate or reject.
